## 재사용할 저장·검증 노하우

- `libraries.write({scene}, fake_user=True)`만으로 미연결 Action 보존을 가정하지 않는다.
  Multi가 native Action4개 누락을 확인했으며 이번 연구도 muted NLA와 `{scene,*actions}`를
  명시 저장하고 별도 프로세스로 전체 커브/키를 해시 대조했다.
- Blend의 커브 보존과 GLB의 실제 sampler 시간/TRS 보존을 따로 검사한다.
  NLA 옵션 설정이나 스킨/클립 개수만으로 native 키 exact를 주장하지 않는다.
- 전 클립 최대값뿐 아니라 클립별 최소 면적비·국소 접힘·실제 렌더를 함께 비교한다.
- 손 외부 가중치는 후보 계산 중뿐 아니라 저장·재열기 뒤에도 bit-exact로 확인한다.
- 부피/관통/길이 지표의 ROI가 다르면 실험 간 숫자로 순위를 매기지 않는다.

연구 소스는 `tools/case_studies/skinning/`에 보존했다. 입력 파일은 로컬 의존적이며 저장소에
없다. 다음은 손바닥·관절 기저부 굴곡 면배치와 두께 유지의 국소 topology/cage 연구다.
가중치 후보가 전체 무관통/손가락 보정 완료를 뜻하지 않으며 기본 모델을 대체하지 않는다.
