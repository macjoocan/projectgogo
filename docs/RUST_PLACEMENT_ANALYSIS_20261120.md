# Rust 건축·설치 분석 결과

정리일: 2026-11-20. 로컬 Rust Base Lab v2.7의 문서와 검증 기록을 기준으로 작성했다. 이번 게시에는 분석 결과만 포함한다. 원본 리소스, 추출 데이터, 실행 코드와 공유용 압축본은 로컬에 둔다.

## 현재 목표와 구현 범위

Rust의 플레이어 시점 건축을 WebGL로 재현했다. 사용자가 마지막으로 정한 우선순위는 **설치가 잘되는 것**이다. 후속 작업도 연결 위치, 높이 차, 충돌, 지지면, 회전과 중복 설치를 먼저 다룬다. 모든 장치의 고유 기능 구현을 완료했다는 뜻은 아니다.

| 집계 대상 | 확인 결과 | 해석할 때 주의할 점 |
|---|---:|---|
| 건축 선택 항목 | 22개 | L자·U자 계단의 반전 형태를 포함한다. |
| 일반 설치 아이템 정의 | 536개 | 스킨·씨앗·묘목·이벤트 항목을 포함한다. 서로 다른 기능 536개라는 뜻은 아니다. |
| 런타임 전체 타입 | 558개 | 건축 22개와 일반 설치물 536개의 합이다. |
| 일반 설치물의 원본 모델 반영 | 535/536개 | 보이는 메시가 없는 `door.closer`는 작은 시험용 외형을 사용한다. |
| 모델 조립 정보 | 기본 104개 + 추가 521개 | 등급·변형 때문에 아이템 수와 일치하지 않는다. |
| 파일 검사 대상 | 메시 1,554개·텍스처 517개 | 메시 좌표·인덱스와 참조 파일을 검사했다. |

설치물 536개는 이번 분석에 사용한 설치본의 `ItemModDeployable` 정의를 기준으로 한다. 이후 게임 업데이트의 전체 항목 수를 보장하지 않는다. 배 전용 건축 도구 부품은 현재 범위에 포함하지 않는다.

## 데이터 분석에서 확인한 점

프리팹에서 아이템을 거꾸로 찾는 방식만으로는 77개 정의를 놓쳤다. 아이템 정의 전체를 수집하고 GUID 참조를 연결해 설치 항목을 대조했다. 외부 파일 참조는 참조한 파일의 맥락에서 해석해야 한다. 이름이 비슷한 모델을 연결하는 것으로 이 검사를 대신할 수 없다.

원본의 설치 거리, 회전, 재료와 표면 각도 조건을 읽었다. 데이터를 확보한 범위와 런타임에서 실제로 적용한 범위는 구분한다. 예를 들어 최소 거리와 복합 설치 조건을 모두 원본처럼 적용한 상태는 아니다.

지형은 원본 `CraggyIsland_Nexus`의 1,024m 정사각형 영역을 사용했다. 1,025×1,025 높이 표본을 4칸 간격으로 줄여 257×257, 총 66,049개 표본을 반영했다. 사용자의 서버에서 생성한 절차적 맵은 아니다. 도로·기념물·수목 배치와 지형 재질 전체는 재현하지 않았다.

## 건축과 설치 판정

기초 옆 지면에서도 연결점을 선택하고, 위층 벽·천장·사각 및 삼각 지붕을 이어 붙이도록 수정했다. 진입 계단과 경사로는 높은 끝을 기초 가장자리에 맞춘다. 계단은 1.5m, 경사로는 0.75m 높이 차를 연결하며 아래 방향으로 이어 설치할 수 있다.

빈 바닥 프레임은 발판이 아니다. 그릴이나 닫힌 해치를 설치하면 발판이 생기고, 해치를 열면 아래로 통과한다. 자물쇠와 자동 닫힘 장치는 설치된 문 등에 부착한다. 자동 닫힘의 3초 지연은 시험값이다.

v2.7에서는 다음 문제를 수정했다.

| 문제 | 현재 처리 |
|---|---|
| 앞쪽 지형 대신 뒤의 구조물이 선택됨 | 조준선에서 지형과 구조물 중 먼저 닿는 면을 사용한다. |
| 벽 뒤 수면에 설치됨 | 중간에 있는 벽이 수면 배치를 막는다. |
| 빈 프레임이 가구·천장등을 지지함 | 일반 설치물의 지지면에서 제외한다. 프레임용 그릴·해치 부착은 유지한다. |
| 바닥 아래·옆면에서 상자를 설치함 | 위쪽 면이 필요한 설치물은 아래·옆면을 거부한다. |
| 경사 지붕의 설치물이 처마 높이로 내려감 | 실제 조준 면의 높이를 사용한다. |
| 큰 설치물의 가장자리가 플레이어와 겹침 | 설치물의 회전·크기·높이와 플레이어 반경 0.3m를 함께 검사한다. |
| 급경사가 바닥이라는 이유로 허용됨 | 원본의 수직 방향 각도 조건을 표면 방향에 적용한다. 의자의 30도 허용·45도 거부를 검사했다. |

표면 방향은 `surfaceNormal`로 저장한다. 이 필드가 없는 이전 저장 파일도 읽는다. 이전에 잘못 놓인 설치물을 자동으로 옮기거나 삭제하지 않는다. 기존 `stairs` 키의 모델은 L자 계단으로 맞췄다. 예전 U자 형태가 필요하면 `stairsU`를 사용한다.

## 검증 기록

아래는 기존 v2.7 실행 기록을 정리한 결과다. 이번 문서 게시 작업에서 게임 검사를 새로 실행한 것은 아니다.

- Node 규칙 검사: **66개 통과, 실패 0개**. `node --test tests/*.test.mjs` 기준이다.
- 브라우저 검사: **82개 통과**. 진입 계단 5, 경사로 5, 프레임 4, 해치 6, 부착 8, 추가 설치물 19, 상층 건축 11, 측면 연결 6, 기존 스냅 7, 설치면 11개다.
- 두 브라우저 실행에서 자동 조준이 목표를 벗어났다. 앱 변경 없이 별도로 다시 실행해 통과했다. 최초 실행부터 모두 통과한 것으로 해석하지 않는다.
- 공유 폴더에서도 Node 66개와 신규 브라우저 설치면 11개를 다시 확인했다. 반복한 11개를 위 82개에 더하지 않는다.
- 공유 ZIP은 CRC와 파일별 SHA-256을 확인했다. 2,900개 파일이며 압축 크기는 1,028,007,083바이트다.

자동 검사는 구현한 규칙의 회귀를 확인한다. 원본 Rust 서버와 모든 배치 사례가 같다는 증거는 아니다. 모든 스킨을 사람이 화면에서 하나씩 대조한 것도 아니다.

## 남은 차이와 후속 작업

충돌은 회전된 경계 상자와 높이를 이용한 근사 검사다. 원본의 모든 충돌체, 특수 연결점, 복합 조건과 서버 판정 순서를 그대로 옮기지는 않았다. 안정성은 시험용 계산이고 건축 권한 반경 16m도 호환용 값이다. 도로·기념물·안전 구역의 건축 금지 영역은 완성되지 않았다.

경사면에서 모델을 기울이는 표현과 여러 접촉점 검사가 남아 있다. 이중문·해치 애니메이션, 장갑 해치의 관절, 사다리 등반도 단순화했다. 전기·산업 장비·함정·가구·차량의 고유 동작을 모두 구현하지 않았다. 부지당 설치 수는 500개로 제한한다.

다음 작업은 원본과 같은 배치 사례로 충돌·지형·특수 연결점을 비교하는 것이다. 장치별 기능 확장은 사용자가 다시 요청할 때 범위를 정한다.
