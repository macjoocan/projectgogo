## 이미 확인한 실패를 반복하지 않기

- 리그 고정 작업에서는 관절을 옮겨 skin 문제를 가리지 않는다. 변경이 필요하면 별도 리그 버전과
  기존 모션 재검증으로 분리한다. 이름70개가 같아도 Body/Head/Legs bind가 같다는 뜻은 아니다.
- 손 전체 균일 축소/일괄 smoothing만으로 해결했다고 쓰지 않는다. 최대 늘어남이 개선돼도
  Idle의 삼각형 면적·기저부 접힘이 악화하면 미채택이다.
- 중립 표정부터 인상이 달라지면 기존 얼굴을 기본으로 유지한다. 기존 눈·입 위에 덧씌우는
  잔상도 검사하되, 정리가 얼굴 전체 교체로 확대되면 국소 면 배치부터 재검토한다.
- 새 모델에 이전 검사 수치를 승계하지 않는다. 5종/125표본·15자세 smoke·278목록 표본·전체
  연속시간/전신 무관통은 다른 검사다.
- Blend 곡선 보존, GLB native 시간키 보존, 웹 GPU/외형을 따로 검사한다. NLA 옵션만으로 보존을
  선언하지 않는다. COLOR_0·alpha와 사용자 기본 Scene 열기를 실제 출력에서 확인한다.
- 실패 후보는 별도 복사본에 보존하고 기본 다운로드/작업 화면을 자동 교체하지 않는다.

## 인계 구조

`source/`는 요청서·원화·기준 리그·프롬프트·재현 코드, `raw/`는 덮어쓰지 않는 생성 원본,
`work/`는 후보, `final/`은 선택한 검수용 출력, `preview/`는 같은 조건 비교,
`validation/`은 범위/수치/실패/해시/재열기·웹 결과를 둔다. manifest에는 stable ID·버전·출처·사용
범위·공급자/job·파일 해시·QA·사람 판정을 나눠 기록한다. final이라는 폴더명은 승인 상태가 아니다.
새 모델은 새 ID, 같은 모델 보정은 같은 ID의 새 버전으로 관리한다.
