# Royal Smash — 오프라인 검증 최종 판정

## 결론

현재 로컬 환경에서 가능한 초기 실행 관찰과 결과 재검증을 마쳤다. **게임 전체 통신 검증은 미완료이며, 현재 오프라인 실행 경로는 라이선스 확인 단계에서 막힌 상태다.** 동일 환경의 반복 부팅은 중단한다. 비탐지나 영구적인 무통신을 보장하지 않는다.

## 재확인한 근거

- 빈 환경 ADB 명령 80회 모두 성공.
- 게임 초기 실행 관찰 33.58초 완료. 5개 시점의 전용 프로세스군 외부 TCP 연결은 모두 0개. 주기적 관찰이지 전수 패킷 검증은 아니다.
- 별도 합성 UDP 패킷은 Windows WFP의 DROP 이벤트와 전용 방화벽 규칙 이름까지 일치해 실제 차단을 입증했다. 게임/에뮬레이터의 모든 UDP 패킷을 시험한 것은 아니다.
- 게임은 `com.pairip.licensecheck.LicenseActivity`에 머물렀다. 로그에 `Local install check failed due to wrong installer`가 기록됐다.
- 같은 로그가 Play 서비스 요구 버전 `212800000`, 설치 버전 `201817023`을 보고한다. 라이선스 서비스 연결 자체는 되었으나 `Licensing service could not process request`로 끝났다. 이를 외부 인증 서버와 연결됐다는 증거로 해석하지 않는다.
- 확인한 로컬 분석 SDK에는 Android 30 `google_apis` ARM64/x86_64 이미지뿐이다. 이 점검으로 모든 다른 환경의 가능성이 없다고 단정하지는 않는다.
- 게임 UID DROP 카운터 0, PCAP 시간축 미보정은 그대로 한계로 유지한다. 이 값들을 무통신 증거로 사용하지 않는다.

## 중단 경계

정상 설치 출처와 호환되는 Play 서비스/라이선스 환경을 현재 로컬 자료만으로 확보한 경로가 없다. 서비스 버전만 올려도 라이선스 문제가 해결된다고 보장할 수 없다. 사용자 조건에 따라 온라인 인증, 설치 출처 위장, 라이선스 우회, 탐지 은폐로 확장하지 않았다. 실제 플레이까지의 통신 검증 성공으로 보고하지 않는다.

## 보존과 폐기

사용한 게임 디스크·스냅샷·키·임시 APK·서버 상태 파일 등 전용 8개 경로가 삭제됐음을 다시 확인했다. 일반 삭제이며 포렌식 보안 삭제는 아니다. 원본 XAPK, 추출 APK, 정적 분석 결과, 로그, 스크린샷, 차단 규칙은 보존했다.

이미 복구한 7개 클래스의 생성자 기본값 51개도 중복 여부와 float32 원시 비트를 재검증했다. 이 값은 실제 씬/프리팹에서 덮어쓴 최종 플레이 수치가 아니다.

기계 판독 재검증 결과와 근거 파일 SHA-256: `FINAL_VALIDATION.json`.
