# 일회용 실험실 사전 점검

2026-09-15. 로컬 설정과 스크립트만 읽었으며 게임 실행, 설치, 외부 요청, 환경 삭제는 하지 않았다.

## 판정: 기존 환경 그대로 실행 불가 — 보완 후 재검증 필요

- 기존 런처 `run_ascii_safety_scheduled.ps1`에는 `restrict=on,ipv6=off`, 스냅샷 사용/저장 금지, 메트릭/크래시 보고 비활성화 옵션이 있다. 이는 설정 증거이며 현재 통신 차단 성공의 증거가 아니다.
- `verify_offline_lab.ps1`는 읽기 전용이 아니다. ADB를 시작하고 게스트 네트워크 설정을 바꾸며 외부 IP로 ping을 시도한다. 이번에는 실행하지 않았다.
- 검증기는 프로세스/연결 조회에서 오류를 숨긴다. 연결 조회 실패가 빈 결과로 해석될 수 있고, TCP 한 시점만 확인하므로 UDP/DNS 및 과거 전송을 검증하지 않는다. 모든 조회 성공을 필수로 하고 실패/불명확 상태를 차단해야 한다.
- `stop_offline_lab.ps1`는 종료 뒤 남은 모든 emulator/qemu 프로세스를 강제 종료할 수 있다. 특정 일회용 인스턴스만 대상으로 제한해야 한다.
- 해당 종료 스크립트는 AVD 디스크와 스냅샷을 삭제하지 않는다. 기존 AVD에는 userdata, 캐시, 암호화 키 이미지와 snapshots 폴더가 남아 있다. 스냅샷 저장 금지 옵션은 디스크 폐기를 의미하지 않는다.
- 기존 AVD는 x86_64/API 30이고 Royal Smash의 네이티브 ELF는 앞선 분석상 ARM64다. ARM 변환 호환성과 오프라인 로딩 성공은 아직 미검증이다.
- 점검 시 adb/emulator/qemu 이름의 프로세스가 관찰됐다. 소유권과 격리는 확인하지 않았으며 종료하거나 변경하지 않았다. lab-runtime.json은 과거 기록이므로 현재 상태로 취급하지 않았다.

## 실제 시험 전 필수 조건

1. 기존 분석 AVD를 재사용하지 않고 별도의 사용자 데이터/캐시/스냅샷 경로를 갖는 새 전용 인스턴스를 준비한다.
2. 첫 부팅부터 적용되는 통신 차단을 검증한다. 조회 오류, 미확인 네트워크 경로, 차단 실패가 있으면 게임을 실행하지 않는다.
3. 서버 접속 없이 로컬 패키지만 시험한다. 로그인 또는 CDN 자료가 필요하면 중단한다. 에뮬레이터/루팅 탐지 회피는 하지 않는다.
4. 시험 종료 시 정확히 해당 인스턴스만 종료하고, 실제 경로가 전용 실험 디렉터리 내부인지 확인한 뒤 해당 쓰기 가능한 디스크와 스냅샷을 폐기한다. 결과 파일만 별도 보존한다.
5. 분석 환경이나 그 복제본을 온라인으로 전환하지 않는다. 폐기는 이미 발생한 전송을 취소하거나 절대적인 비탐지를 보장하지 않는다.

이번 점검은 실행 전 구성 감사이며, 격리 검증 통과나 게임 실행 성공 판정이 아니다.
