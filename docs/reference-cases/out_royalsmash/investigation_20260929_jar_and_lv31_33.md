### 1.2 조각이 안 보인다는 증상 — 재현 조건을 찾았다

런타임 경로(`Object.Instantiate`)에서는 조각이 정상으로 나온다.
**에디터 도구 경로(`PrefabUtility.InstantiatePrefab`)에서는 안 나온다.**

`SpawnBroken()` 의 `t.SetParent(null, true)` 가 프리팹 인스턴스 구조 변경 제한에 막힌다.
조각이 원본에 붙어 있는 채로 원본이 `SetActive(false)` 되니 같이 꺼진다.

```
프리팹 연결 O  →  조각 parent = JamJarRed_1 · activeInHierarchy = false  (안 보임)
프리팹 연결 X  →  조각 parent = 루트        · activeInHierarchy = true   (보임)
```

`RsLevelBuilder` 같은 에디터 툴에서 레벨을 구워 확인했다면 이 경로에 걸린 것이다.
**빌드·플레이 모드에는 해당 없다.** 대신 에디터에서 파괴를 확인할 때는 `Object.Instantiate` 로 세워야 한다.

### 1.3 남은 진짜 누락 — 파티클

원작 `JamJarRed_1` 의 `explosionEffect` → `PS_Jar_Red` 에 이미터 5개(root flash burst4 · JamParticle burst6 · Glass burst12 · JamParticle(1) burst50 · ImpactCircle burst8).
색 6종 전부 별도 프리팹이고 `jar_break` SFX 도 따로다.
**이식본에는 파티클도 SFX도 없다.** "깨지는데 밋밋하다"는 여기서 온다.

### 2.4 해석

- **솔버 수렴 문제가 아니다.** 반복을 6에서 120으로 20배 올려도 그대로 무너진다. 접촉 마찰·관성 모델 쪽이다.
- **임계가 17.5~20 deg/s 사이**에 있다. 데이터값 25는 임계를 한참 넘는다. lv31·lv33 의 20 deg/s 는 임계 바로 아래다.
- **마찰 ×2 로 완전히 사라진다.** lv32 는 유리병(동마찰 0.27 · 조합 Average) 로 쌓은 7.5 m 탑이다.
  받침 면은 PM_Ground(1 / 0.6 · Maximum) 라 잘 잡지만 **병끼리 미끄러진다.**
- **시작 램프가 원인이 아니다.** startup 을 0.5까지 늘려도 그대로다. 1.0 에서만 사라진다.
  "초기 settle 동안 회전 정지" 안은 **붕괴를 약 1초 늦출 뿐**이다(실측: t2.0 에 이미 같은 수준).

### 2.5 단정하지 않는 것

| 항목 | 상태 |
|---|---|
| 사용자가 본 lv31·lv33 붕괴 | **이 하네스로는 재현 안 됨.** 6초간 멀쩡하다. 브라우저 런타임 확인 필요 |
| 원작 동등성 | 미확인. "원작과 다르다"고 말할 근거가 없다 |
| 충돌 콜백 | 에디트 모드라 바닥 접촉 파괴가 안 돈다. 실제로는 떨어진 블록이 파괴되어 사라진다 |
| 프레임 변동 | 고정 스텝이라 WebGL 의 가변 프레임·`maximumDeltaTime 0.025` 클램프 영향이 빠져 있다 |
