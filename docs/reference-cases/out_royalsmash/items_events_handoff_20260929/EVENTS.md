# 서버 없는 이벤트 6종 [전체 자체/교체용 v1]

원본 참고: RoadRunner에는 step ladder/claimed steps, DartNight에는 score/track/multiplier, TroubleTrap에는 requiredWins/lobbySize/prize, PowerPlay에는 session/bots/cooldown, SmashLeague에는 difficulty 기반 승리 진입점, DailyTask에는 counter/claim API가 있다. 출처는 `source_declarations.json`. 아래 수치와 계산은 그 구조를 참고해 새로 정했다.

## 공통 일정과 승패

- 기본은 **수동 참가로 시작하는 개인 기간제**. 서버의 요일별 일정은 재현하지 않는다. 참가 시 startUtcMs와 endUtcMs를 저장. 일일 미션도 참가 후24시간이며 자정 리셋이 아니다.
- 해금 판정 currentLevel>=unlockLevel. 디버그 전체 해금은 별도 debug 설정이고 기본 false.
- 상태 `Locked → Available → Active → Settled → Archived`. 수령 가능 보상은 별도 ledger로 보존, Archived가 미수령 보상을 삭제하지 않는다.
- Active에서는 중복 참가 불가. Settled 후 해당 이벤트의 cooldown 경과 및 결과 확인을 마치면 새 instanceId로 참가 가능. 이전 미수령 보상은 수령함에 보존.
- `LevelAttemptStarted` 시 참여 중 이벤트 instanceId를 snapshot. 이후 참가한 이벤트에 이전 시도 점수를 소급 지급하지 않는다. 승리 커밋 시각이 **endUtcMs 미만**이어야 점수 반영. 정확히 종료 시각이면 먼저 정산한다. 종료 전에 시작한 레벨도 종료 이후 클리어하면 점수 없음.
- 성공은 finalWon 1회만, 패배는 finalLost/quit/강제종료 복구1회만. 이어하기 창/이어하기 구매는 패배가 아니다. 난이도는 levels.json difficulty 0/1/2를 사용.
- 기본 클리어 보상과 이벤트 보상은 독립. 재도전/이어하기를 쓴 승리도 별도 제한 명시가 없으면 인정한다.

## 1. 연승 사다리 — local_streak

해금25, 기간72시간, 종료 후쿨다운0. 절대 연승 경계 [2,4,6,8,10]. 성공마다 eventStreak+1, 최종 실패 시 eventStreak=0. **최고 도달 경계와 확보 보상은 유지**한다. 각 단계는 인스턴스당1회 수령. 중간실패 후 다시2연승을 해도 1단계 재지급 없음.

보상 순서: 코인100 / BigBall1 / 코인250 / InfiniteMoves1 / 코인500+Barrage1. 10연승 달성 시 즉시 Settled(성공), 전 단계를 자동 지급하지 않고 일괄 수령 버튼 제공. 시간 만료 시 도달한 보상만 보존.

화면: 현재 연승·남은 시간·5단 사다리·도달/수령 상태. 최종 실패 전 포기창에는 '현재 연승이 초기화됩니다' 표시. 이미 확보한 보상까지 잃는다고 쓰지 않는다.

## 2. 수집 트랙 — local_collection

해금20, 기간72시간. 성공 기본 점수 Normal1/Hard2/SuperHard3. 이벤트 내 **승리 직전 연승**에 따른 배수: 0→1배,1→2배,2이상→3배. 점수=기본×배수 지급 후 streak+1. 최종 실패는 streak만0, 누적 점수 유지. 아이템/이어하기 사용은 감점하지 않음.

누적 경계 [5,15,30,50,80]. 보상 코인100 / BigBall1 / 코인250 / InfiniteMoves1 / 코인500+Barrage1. 한 번에 여러 경계를 넘으면 모두 claimable. 80 이상은80으로 표시하되 총 획득 점수는 로그에 보존, 즉시 Settled 성공.

원본 DartToken 지갑과 혼용하지 않는다. 이 이벤트 점수는 instance 내부 정수다. 화면에서 '승리 시 다음 획득량'과 배수/연승을 보여준다.

## 3. 생존 도전 — local_survival

해금30, 참가 후48시간, 목표7연승. 참가자 표시는 **플레이어+모의 상대19명**. 시드별 생존 인원 계획을 참가 시 고정하되 v1 기본은 [20,17,14,11,8,6,4,3]으로 시작+7단계를 제공한다. 이 표는 동시 접속 인원이 아니다.

성공마다 step+1 및 survivors=표[step]. 최종 실패/포기면 즉시 탈락, 보상0,30분 재참가 쿨다운. 7연승 성공은 코인 상금3000/최종생존3을 **10단위 올림**하여 개인1000 지급 가능 상태. 일반식 ceil(pot/survivors/10)*10. 성공 후 다음 참가까지24시간. 시간 만료는 미완료/보상0/쿨다운0.

각 새 참가는 새 instance로 처리한다. 이전 창을 재열어 패배를 취소할 수 없다. 연출은 한 단계 이동→모의 탈락→인원 텍스트 갱신. 진행 확정/저장은 연출 전에 끝낸다. 데모 인원계획을 원본 분포로 표기하지 않는다.

## 4. 단기 레이스 — local_race

해금35, 세션2시간, 플레이어+모의 상대4명. 성공 점수1/2/3, 패배는 점수 유지. 목표 점수를 달성해도 **2시간 끝까지 진행**. 종료 시 점수 내림차순, 동점은 고정 competitorId 오름차순으로 정렬(player id=0).

모의 상대 최종점수 목표는 seed로 각각 [8,12,16,20]에 -2~+2를 더해 참가 시 저장. 진행점수는 floor(finalTarget*clamp(elapsed/duration,0,1)). 매 프레임 랜덤을 뽑지 않는다. 앱을 껐다 켜도 같은 경과 시각 점수가 같다. 원본 봇 모델과 동일하지 않다.

최종 보상: 1위 코인500+BigBall1,2위300,3위150,4~5위50. 모두 결과창에서1회 수령. 종료 후30분 쿨다운. 참가 시 무료 무한하트/아이템은 v1에서 없음. 레이스 점수와 일반 연승은 서로 독립.

## 5. 시즌 리그 — local_league

해금50, 기간7일, 플레이어+모의 상대9명. 성공 점수1/3/5. 패배 시점수 유지. 모의 상대 목표 [20,30,40,50,65,80,100,125,150]에 seed로 -5~+5, 최소0; 시간진행식/동점정렬은 단기 레이스와 동일.

순위보상: 1위1000코인+InfiniteMoves1,2~3위500,4~6위250,7~10위100. 종료 후쿨다운0. 원본 최종레벨 이후 챔피언십 진입 규칙은 사용하지 않고 **해금50부터 독립 참가 가능**하게 한다. 레벨700 이후 자동 순환/원본 서버 매칭을 이 이벤트가 책임지지 않는다.

## 6. 일일 미션 — local_daily

해금10, 참가 후24시간. 동시에 미션3개: 승리3회→코인100, 실제 부스터 사용1회→코인100, Hard 또는 SuperHard 승리1회→BigBall1. 모두 완료 후 별도 최종 보상 코인200. 완료와 수령을 구분하고 미션별 수령 ID를 쓴다.

부스터 사용은 ItemUseCommitted만 세고 구매/선택/취소는 제외. 무료 실제 사용은 포함. 실패로 미션 진행을 되돌리지 않음. 최종 보상은 세 미션 **완료** 기준이며 개별 수령 순서를 강제하지 않는다. 시간 만료 시 이미 달성한 보상만 수령함 보존. 미완료 미션은 새 이벤트에 이월하지 않는다.

## 이벤트 화면·알림 순서

로비 상단 핀3개(연승/수집/가장 가까운 종료), 나머지는 '이벤트' 목록. 카드는 Locked/Join/Progress/Claim/Result 상태를 보여준다. 매번 자동 팝업6개를 연속으로 띄우지 않는다.

승리 후 순서: 기본 클리어 로고→기본 결과→이벤트 진행 요약1장(변한 이벤트만)→수령 가능 보상 배지→로비. 보상 수령 애니메이션은 지갑 커밋 후 보여주며 스킵 가능. 수령해야 다음 레벨을 할 수 있게 막지 않는다.

실패/포기창에는 영향을 받는 연승·생존 이벤트만 손실 요약. 최종 실패 커밋 전에는 이벤트 상태 변경 없음. 레이스/리그/수집 누적점수/일일 진행은 유지된다.
