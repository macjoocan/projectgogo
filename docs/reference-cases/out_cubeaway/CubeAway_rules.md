## 0. 좌표 규약
- 방향 이동량: Right=+U, Left=−U, Up=+V, Down=−V
- 면 축: +x U=−z V=+y · −x U=+z V=+y · +y U=+x V=−z · −y U=+x V=+z · +z U=+x V=+y · −z U=−x V=+y
- 머리 = cells[0]. 화살표는 머리 방향으로 나간다.

## 1. 이웃 분류 (SurfaceGraphBuilder.ResolveNeighbor)
현재 복셀 v, 이동 방향 옆 복셀 n = v + step(면 축으로 변환한 방향).
- n이 차 있고 n의 같은 면이 노출 → **Flat**(n의 같은 면)
- n이 비어 있음 → **Convex**: v의 이동 방향 쪽 옆면으로 감아 도는 이웃(노출 안 됐으면 Void)
- n이 차 있는데 n의 같은 면이 덮임(앞에 벽) → **Concave**: 이웃 칸 없음 → 항상 벽

## 2. 경로 계산 (PathChecker.Check)
반복 상한 200회. 다 돌면 **성공(탈출)** 처리.
- Flat: 다음 칸. 다른 화살표 점유면 Blocked(자기 몸 무시)
- Convex: cornerless 모서리면 옆 면으로 넘어감(방향 변환). 아니면 **비행(HollowCrossing)**
- Concave: **BlockedByWall** (cornerless 와 무관)
- Void / 그래프에 없는 칸: 비행
- 칸에 들어갈 때마다 기믹 검사(CheckGimmicks)

### 비행(HollowCrossing) — 세 거리 비교
- 벽: 진행 방향을 마주 보는 노출 면, 측면 ±0.5 이내, 높이가 비행면에 닿는 것 중 최근접
- 화살표: 진행 직선 위 같은 평면 셀을 가까운 순으로, 다른 화살표가 점유한 첫 칸
- 착지: 진행 직선 위 첫 같은 평면 노출 면
- 판정: 벽 ≤ 화살표 and 벽 ≤ 착지 → 벽 막힘 / 화살표 ≤ 착지 → 화살표 막힘 / 착지 있음 → 착지 후 계속(비행 칸 수만큼 steps 가산, 경로엔 착지 칸만 추가) / 없음 → 탈출
- 착지 칸에 화살표가 있으면 같은 거리라 화살표 막힘

## 3. 기믹
- **changer**: 그 칸에서 exitDir 로 꺾음
- **reverse_changer**: 초기값 = exitDir. 한 경로 안에서 같은 칸을 다시 지나면 반대 방향. 판 상태는 **발사 결과가 막힘이 아닐 때(성공·멈춤)** 경로 위 reverse_changer 를 뒤집음. 막힌 발사는 안 뒤집음
- **pause**: 들어간 칸이 pause 이고 ShouldStopOnPause 면 멈춤
  - SkipPauseCells 에 있는 칸이면 안 멈춤. 단 double 을 꼬리 쪽에서 쏜 경우엔 집합에 있어도 멈춤
  - SkipPauseCells 는 빈 집합으로 시작. 멈출 때마다 그 칸 추가(일반=누적, double=비우고 그 칸만)
  - 멈춘 뒤 몸: 길이 n, 멈춘 스텝 p → 새 i번째 칸 = i≤p 면 경로[p−i], 아니면 기존 몸[i−p] (뱀 이동, 홈 건너뛴 칸은 경로에 없음)
  - 멈춘 뒤 방향: 일반 발사 = 멈춘 스텝의 진행 방향 / double 꼬리 발사 = 몸 모양으로 재계산(1칸이면 진행 방향)

## 4. double
- **탭한 칸 위치로 방향 결정**: 탭 인덱스 ≥ 몸 길이/2 (꼬리 쪽 절반) → 꼬리에서 역방향 발사, 아니면 머리 방향
- 탭 위치가 없는 호출(연결 묶음의 비탭 화살표 등): 머리가 막히면 꼬리 시도, 꼬리가 통하면 꼬리 채택
- 꼬리 발사 출발 = 꼬리 칸, 방향 = 몸 목록을 뒤집어 계산한 머리 방향(실패 시 원래 방향을 꼬리 면으로 변환해 반대)

## 5. 연결(branch) 묶음
- 묶음 전원의 발사를 계산(같은 묶음끼리는 점유에서 제외된 상태로 계산하는 것으로 보임)
- 탭한 화살표만 탭 위치 사용, 나머지는 막히면 꼬리 시도 허용
- 하나라도 막히고 그 막힘이 가장 이른 pause 보다 먼저(또는 pause 없음) → **묶음 전체가 함께 튕김**
- 그 외(막힘 없음, 또는 가장 이른 pause 스텝 ≤ 가장 이른 막힘 스텝) → **화살표별로 따로 처리**:
  멈춤 결과 = 각자 그 자리에서 멈춤(pausing 집합에 등록) / 막힘 결과 = 그 화살표만 튕김(bouncing 집합 등록) /
  성공 결과 = 그 화살표만 발사·제거(FinalizeSuccessfulFire). 묶음이 한 덩어리로 움직이지 않는다
- 하트: 튕기는 목록 중 아직 튕기는 중이 아닌 화살표가 하나라도 있으면 1회 차감(묶음 전체 튕김·혼합 모두 동일)

## 6. 하트·이동수
- 막힌 화살표가 **부딪히는 순간** 하트 −1. 조건: 레벨 MaxHearts ≥ 1 이고 현재 하트 ≥ 1 → **MaxHearts=0 이면 하트 무제한**
- 바운스: 0.93초(앞으로 0.35 비율 간 뒤 원위치), 바운스 중 다른 화살표 탭 가능
- MoveCount: MaxMoveCount ≥ 1 일 때 탭마다 −1 (전 레벨 0 → 미사용)
- 부활: 광고 또는 2000코인으로 하트 +2
